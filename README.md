# 方得 Funday ✦

一个从“想出去玩”到“马上出发”的轻量活动产品。

## 当前版本

**V0.4.1 · 用户闭环**

当前已完成从静态高保真原型到 React + Vite 工程化前端，并补齐本地数据状态层：

- React + Vite 工程化结构
- 8 个核心页面组件化迁移
- 定制偏好与时长 → 生成今日方案
- 方案 → 点位详情
- 点位收藏状态持久化
- 活动筛选 → 报名 → 报名状态持久化
- 发起活动 → 表单提交 → 发起记录持久化
- “我的”页面实时汇总收藏、方案、报名、发起记录
- localStorage 本地持久化，刷新页面后状态保留

## 技术栈

- React
